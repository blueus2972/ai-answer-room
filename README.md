# AI 답변 비교실

퀴즈와 독립된 웹앱 및 개인용 Chrome 확장 프로그램입니다.

주소: https://uriban-ai-compare.vercel.app/compare

`npm install`, `npm run dev`로 실행합니다. `npm test`, `node tests/compare-browser.mjs`, `node tests/extension-browser.mjs`로 검증합니다. `npm run package:extension`으로 ZIP을 생성합니다.

주소 변경으로 기존 브라우저 기록은 이전 비교실에서 전체 백업한 JSON을 새 비교실의 백업 가져오기로 불러오세요. 확장 프로그램 0.2.0은 새 도메인만 허용합니다. 기존 설치 파일 교체 후 chrome://extensions에서 새로고침하세요.
