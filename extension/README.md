# 우리반 AI 비교 연결 (개인용 Chrome 확장, 0.2.1)

설치: public/downloads/uriban-ai-bridge.zip 압축 해제 → chrome://extensions → 개발자 모드 → 압축해제된 확장 프로그램 로드 → manifest.json 폴더 선택. 비교실을 새로고침합니다.

지원: https://uriban-ai-compare.vercel.app/compare 에서만 시작. Gemini, Claude, ChatGPT, Grok의 웹 UI에 질문을 입력하고 한 번 전송한 뒤 응답을 읽습니다. 쿠키·비밀번호·내부 API를 사용하지 않습니다. 연결 도중 로그인·CAPTCHA·약관은 사용자가 직접 처리합니다. 사이트의 자동화 관련 이용 조건이 적용됩니다.

권한: storage(브라우저 세션 동안 작업 상태 보존), alarms(10분 작업 만료); 비교실과 네 AI 호스트만 접근합니다. content script는 작업으로 생성한 탭에 할당된 요청이 있을 때만 질문 전송·응답 수집을 실행합니다. 중복 전송을 막기 위해 보내기 버튼을 누르기 전에 상태를 기록합니다. 모호한 전송은 자동 재시도하지 않습니다. 중지는 가능한 경우 AI의 중지 버튼을 누르며 대화 삭제나 요청 취소를 보장하지 않습니다.

응답 완료는 화면의 생성 중지 버튼 및 15초간 텍스트 변화 없음을 사용해 판단합니다. 긴 추론·웹 검색 등은 중간 멈춤이 있을 수 있습니다. 5분 수집 제한, 2분 입력창 대기 제한. AI 확인으로 원문을 볼 수 있고 부분 응답도 보관합니다.

검증 범위: Chrome 확장 통합 테스트의 모의 AI 페이지. 실제 로그인 계정 네 곳의 확장 실행은 설치 후 점검 필요. 개인용 개발 버전이며 Chrome Web Store에 게시되지 않았습니다.

소스: extension/; 패키지 생성: scripts/package-extension.mjs. 개인정보·프롬프트·답변을 개발자 서버로 보내지 않습니다.

## 0.2.1 수정

Grok의 질문과 답변이 같은 마크다운 클래스를 사용하는 경우 질문을 답변으로 수집하던 문제를 수정했습니다. 이제 assistant 작성 영역만 수집합니다. 기존 설치는 파일 교체 후 확장 프로그램 새로고침이 필요합니다.
